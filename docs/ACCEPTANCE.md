# P2 验收与实验红线

## 预定义判读线

运行前固定如下规则：

1. 三族均完成真实模型 forward，至少各捕获一个有效路由张量；否则失败。
2. 每个像素或样本上的专家概率和误差不得超过 `1e-4`，不得出现 NaN、Inf 或负概率。
3. 只有原始张量包含 H/W 维度时才标记 `token`；全局路由必须标记 `image`。
4. letterbox 逆映射必须裁掉 padding 并恢复原图宽高；合成热点测试允许误差不超过 2 像素。
5. 演示视频时长为 `120.0 ± 0.1` 秒。
6. 任一输入越出路径白名单必须拒绝；产物不得记录绝对路径或凭据。

负结果可接受，但必须保留失败日志、配置、版本和机器可读证据，且不能更改上述门槛来使结果通过。

## 对照与统计口径

三族使用同一张 COCO8 图片、相同 `imgsz=160`、batch=1、float32、CPU、seed=0 和一次 forward。这里比较的是路由接口与空间粒度，不比较模型精度。单 seed 图只作为功能证据；本仓库不声称任何精度提升或下降。后续若声称指标变化，必须保持数据、预算、增广和评测口径一致，并原则上运行至少 3 seed，报告均值与离散程度。

MOT 使用“router-only replay”：在 COCO8 上训练 10 epochs 后只提取路由器张量，再加载到同 seed、同配置初始化的骨干中。这样用 25 KB 状态即可复现空间接口，不等价于完整训练 checkpoint 的精度状态。当前代表专家的绝对概率范围约为 `0.500001`；相对对比图仍同时保留 min/mean/max/range。该视觉差异不能被表述成检测精度提升。

## 版本、安全和许可

- `spatial_records.json` 记录腾讯 checkout commit、dirty 状态、Python/Torch/OpenCV 版本、模型配置路径与 SHA-256。
- COCO8 图像仅用于研究复现；使用者需遵守 COCO 数据许可。仓库保留单张低分辨率验收输入的派生可视化与哈希。
- 输入通过 `dataset-root` 白名单约束；日志只写数据集相对路径。
- 工具不接收或执行 shell 字符串，不调用 `eval`，不修改腾讯源码。

## PR 描述模板

### 改动摘要

说明新增的路由 adapter、空间语义和下游用途。

### 测试证据

列出命令、环境、结果目录、单测和视频时长校验。

### 消融数据

列出同数据同预算对照；没有指标消融时明确写“功能型交付，无精度提升声明”。

### 已知局限

列出不支持族、image-level 不能解释为空间定位、单 seed 边界、性能开销与 fallback。
